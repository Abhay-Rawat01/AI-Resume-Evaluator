# 🤖 AI Resume Evaluator

An AI-powered Resume Evaluator that analyzes resumes against a given
job description and evaluates candidates based on their skills,
experience, and relevance to the role.

## 🚀 Features

- 📄 Supports PDF and DOCX resumes
- 🤖 AI-powered resume analysis
- 🎯 Compares resumes with job descriptions
- 📊 Generates candidate scores
- 🏆 Identifies top candidates
- 🔐 Keeps API keys secure using environment variables

## 🛠️ Technologies Used

- Python
- Groq API
- LLM
- Pydantic
- PyPDF
- python-docx
- python-dotenv

## ⚙️ How It Works

```text
Resume Files
     ↓
PDF / DOCX Text Extraction
     ↓
Resume Content
     ↓
Job Description
     ↓
AI / LLM Analysis
     ↓
Skills & Experience Evaluation
     ↓
Candidate Score
     ↓
Top Candidates
